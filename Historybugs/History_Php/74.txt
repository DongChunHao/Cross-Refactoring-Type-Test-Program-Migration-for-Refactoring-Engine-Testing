Expected behavior:
Inside the moved class Test, keep `self::foo()` unchanged. `self` always refers to the class where the code is written, so no namespace qualification should be applied to the `self` keyword.

Underlying cause:
The reference rewriter treats `self` as an ordinary class name identifier during namespace adjustment. When the class is moved into a new namespace, it incorrectly applies namespace qualification to the `self` keyword. The bug only surfaces when splitting a multi-class source file into a separate file for the moved class.
