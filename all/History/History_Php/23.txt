    static private function fs(){}
    function fa2()
    {
        self::fs();
    }
}

Refactoring rule: When analyzing `self::` static calls inside a method to be pulled up, correctly resolve that `self` is bound to the original declaring class at parse time. Underlying cause:
The dependency scanner does not differentiate `self::` / `static::` / explicit-class-name static invocations. It treats `self::fs()` as if it were an explicit `B::fs()` call and does not account for the compile-time binding of `self` changing when the method’s lexical host class changes.
