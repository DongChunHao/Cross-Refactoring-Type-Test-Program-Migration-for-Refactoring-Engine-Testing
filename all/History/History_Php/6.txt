<?php
trait A{
    function a(){
        print $a;
    }
}

interface C{
    function a();
}

class B implements C{
    use A;
    public function b(){
        $this->a(); // <caret> invoke Change signature refactoring here
    }
}

Refactoring type: Change Signature
Refactoring target: method a, call site $this->a() inside B::b()
Action: add new parameter $a with default value 2
Refactoring rule: When changing the signature of a trait method that is used by a class implementing an interface, the refactoring must check the corresponding interface method signature. Any changes must maintain signature compatibility with the interface contract; if the change breaks compatibility, the refactoring should warn the user and refuse to apply the change, or update the interface method signature together.
*/
